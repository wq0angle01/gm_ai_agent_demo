# 终端命令执行约定

用户已在 Qoder 插件设置里把「终端」设为**完全访问权限**：所有命令直接执行，无审批弹窗、无沙箱隔离。
因此"是否要拦一下"这件事只能由本规则承担。以下约束优先级高于效率。

## 必须做：减少无谓的确认与刷屏

- **只读探测合并成一条命令**。同一批检查（读文件 + 查进程 + 查端口 + 查配置）用 `Write-Host` 分段标题在一条命令里跑完，
  禁止拆成 4~6 次单独调用。
- **互不依赖的查询放在同一批发出**（并行），不要串行等待上一个返回。
- **耗时命令一律后台**：`mvn package`、`java -jar` 启动、测试套件、下载依赖，
  用 `is_background=true` 起，随后按需取输出；不要在前台阻塞到超时。
- **需要等待的场景用一条带 `Start-Sleep` 的命令一次取回结果**，不要反复轮询刷屏。

## 仍然必须先问一句（即使系统不再拦）

自动执行模式下没有人复核，错了是静默出错。以下四类保持口头确认：

- **删除与覆盖**：`Remove-Item`、`DeleteFile`、`mv` 覆盖、`git clean` / `reset --hard` / 强推。
- **结束进程**：`Stop-Process`、`taskkill` —— 可能误杀用户自己跑着的服务、IDE 或本会话的宿主进程。
- **改动系统状态**：注册表环境变量、用户级/机器级配置、`setx`、服务启停、代理设置。
- **工作区 `E:\ProjectFile\gm_demo` 之外的写入**（设置项「允许修改项目外文件」已放开，不放开我的克制）。

## 禁止：本项目已踩过的环境坑

- 不用 `*>` 重定向捕获 Java 输出：PowerShell 按 GBK 解码 UTF-8 会毁掉中文；改用 `-Dlogging.file.name=xxx.log`。
- 不用 `&&` 连接命令（当前 shell 是 powershell.exe，不支持）。
- 不用 `\uXXXX` 转义书写中文注释或文档：会产生形近错字且不易发现。
- 不把控制台中文乱码当成接口报错：先按 UTF-8 读原始响应再下结论。
- 不为"验证通过"而绕过上面的确认线，也不为省事而省略风险说明。
